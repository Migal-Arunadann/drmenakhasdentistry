## Website Structure

- `index.html` — Homepage featuring editorial practice overview, real clinic photography tour, clinical leadership profile, and evening timings.
- `about.html` — In-depth clinic philosophy, doctor credentials, and sterilization protocols.
- `services.html` — Comprehensive clinical service catalog organized by Prosthodontics, Implants, Restorative & Preventive Care with direct WhatsApp consultation links.
- `contact.html` — Practical contact desk, directions, timings, and direct WhatsApp / Telephone hubs.
- `assets/`
  - `css/main.css` — Custom design system with HSL-balanced palette, typography hierarchy, responsive breakpoints, and accessibility.
  - `js/main.js` — Vanilla JavaScript for live IST clinic status, restrained motion, and accessible mobile navigation.
  - `images/` — Clinic operatory, reception, hallway photography, doctor portrait, and WebP equivalents.
  - `logo/` — Official clinic brand logo and vector assets.
- `sitemap.xml` & `robots.txt` — Search engine optimization metadata.

## Local Development

The site is built with pure standard web technologies (HTML5, Vanilla CSS, Vanilla JavaScript) and requires no build tools or bundlers.

To preview locally:
```bash
# Python 3
python -m http.server 8080

# Or Node.js npx serve
npx serve .
```

Then open `http://localhost:8080/` in your browser.
